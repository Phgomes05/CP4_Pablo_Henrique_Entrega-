# Roteiro de apresentação — CP4 (aprox. 2 minutos)

**0:00–0:15 | Abertura**
“Olá, este é meu portfólio pessoal, desenvolvido ao longo dos checkpoints CP1 ao CP4 e publicado no GitHub Pages. O objetivo é apresentar meu perfil, minha formação e alguns recursos que desenvolvi com HTML, CSS e JavaScript.”

**0:15–0:45 | Navegação pelas páginas**
“Na página inicial apresento um resumo sobre mim e meus interesses. Em Currículo estão minha formação e experiência profissional. Também desenvolvi uma página de formulário, uma página de multimídia com áudio e vídeo e uma página com exemplos de Canvas e SVG.”

**0:45–1:15 | Feature JavaScript + persistência**
“Na página inicial, posso salvar meus interesses. Vou selecionar Programação e Tecnologia. Essas escolhas são armazenadas no localStorage do navegador. Agora vou atualizar a página com F5 e vocês podem ver que as seleções continuam salvas. Isso demonstra a persistência dos dados no próprio navegador. O formulário também valida os campos e guarda uma demonstração do último contato localmente; ele não envia e-mail.”

**1:15–1:45 | Evolução e decisões técnicas**
“No CP1 construí a estrutura inicial das páginas. No CP2 trabalhei o layout responsivo com Flexbox e Grid. No CP3 acrescentei interatividade, validação e armazenamento local com JavaScript. No CP4 consolidei o projeto, integrei Bootstrap com classes como container, nav-pills, btn, form-control e table-responsive, mantendo o CSS próprio para personalizar a identidade visual.”

**1:45–2:00 | Acessibilidade e encerramento**
“Também revisei a acessibilidade: textos alternativos nas imagens, contraste de cores, foco visível para navegação por teclado e link para pular direto ao conteúdo. O layout se adapta a telas menores. Essa é a versão final do meu portfólio. Obrigado!”

## Checklist antes de gravar
- Abra o endereço HTTPS publicado em uma janela anônima.
- Mostre as cinco páginas no navegador.
- Na página inicial, salve dois interesses e atualize com F5.
- Se possível, mostre DevTools → Application → Local Storage.
- Grave sua voz e a tela; mantenha entre 1min30 e 2min30.
- Faça o push da versão final e da tag `cp4-entrega` antes da gravação.
